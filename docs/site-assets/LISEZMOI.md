# Images pour le site vitrine

| Fichier | Usage |
|---|---|
| `logo-devhub.png` | Logo (navigation, footer) |
| `favicon.ico` | Icône de l'onglet du navigateur |
| `og-image.png` | Image de partage 1200×630 (Open Graph / Twitter) |
| `hubi.png` | Hubi au repos, fond transparent (hero, coins de sections) |
| `hubi-humeurs-grille.png` | Les 14 humeurs en grille (section Hubi) |
| `hubi-humeurs/*.png` | Chaque humeur seule, fond transparent |

Humeurs (`hubi-humeurs/`) — idées d'usage :

| Fichier | Humeur | Où l'utiliser |
|---|---|---|
| `acting.png` | Au travail (tablette) | « Il suit ton IA » |
| `alert.png` | Alerte | « Il te prévient » / session qui attend |
| `happy.png` | Content (tablette ✓) | Session terminée, appel final |
| `understood.png` | Compris (clin d'œil) | Tâches |
| `listening.png` | Écoute (notes) | Tâches / Ctrl Alt H |
| `laugh.png` | Rire | « Il a de la personnalité » |
| `asleep.png` | Endormi (zzz) | « Il s'endort quand tu ne fais rien », page 404 |
| `sleepy.png` | Somnolent | Plateformes « bientôt » |
| `error.png` | Erreur | Page 404 / erreurs |
| `normal.png`, `excited.png`, `startle.png`, `focused.png`, `fear.png` | Autres | Décor, FAQ, animations |

Vidéo de présentation : `devhub-annonce-v20.MP4` (ton fichier d'origine) — à
mettre dans les assets du site en lecture auto, muette, en boucle.
Captures de l'app : à prendre toi-même dans Dev Hub (accueil, un projet ouvert,
page Hubi, onglets), idéalement en thème sombre par défaut.
